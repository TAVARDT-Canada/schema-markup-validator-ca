# Schema Markup and Structured Data Validator

[![Schema Validator](https://img.shields.io/badge/TAVARDT-Schema.org%20Validator-5b3cf5.svg)](https://tools.tavardt.com/ca/schema-markup-validator/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)

Structured data audit tool for Canadian organizations, evaluating Schema.org JSON-LD conformance, rich snippets readiness, and semantic clarity.

Developed and maintained by the digital architecture and semantic search team at **TAVARDT**.

***

## Semantic Validation Capabilities

* **Structured Data Inspection**: Automated discovery and parsing of JSON-LD scripts and Microdata entity hierarchies.
* **Schema.org Type Verification**: Validates essential entity definitions (Organization, LocalBusiness, WebSite, Article, Product, FAQPage).
* **Syntax and Completeness Auditing**: Identifies malformed syntax, unescaped strings, and missing mandatory properties for rich results.
* **Semantic Conformance Rating**: Standardized 0 to 100 evaluation with actionable technical optimization steps.

***

## Installation and Execution

Requires Python 3.8 or higher using standard library modules.

```bash
git clone https://github.com/TAVARDT-Canada/schema-markup-validator-ca.git
cd schema-markup-validator-ca
python schema_validator.py example.ca
```

For programmatic evaluation in JSON format:

```bash
python schema_validator.py example.ca -json
```
